# 📚 Student Study Planner

A simple and responsive web application that helps students organize,
track, and manage their study tasks.

The application allows students to add tasks with subjects, due dates,
and priorities while tracking their overall study progress.

---

## 🚀 Features

- Add study tasks
- Select subject
- Set due date
- Set task priority
- Mark tasks as completed
- Undo completed tasks
- Delete tasks
- Filter tasks by:
  - All
  - Pending
  - Completed
- Track total, completed, and pending tasks
- Visual progress bar
- Progress percentage
- Tasks saved using browser Local Storage
- Responsive design for mobile devices
- Empty-state message when no tasks are available
